# Leerchecklist

Beantwoord deze punten zonder de bestanden in de repository te openen.

- [ ] Ik kan het verschil tussen een image en een container uitleggen.
- [ ] Ik kan beschrijven wat de Docker-client en Docker-daemon elk doen.
- [ ] Ik kan `127.0.0.1:8080:8080` van links naar rechts uitleggen.
- [ ] Ik kan in het Dockerfile buildtime- en runtime-instructies aanwijzen.
- [ ] Ik kan uitleggen waarom `EXPOSE` geen hostpoort publiceert.
- [ ] Ik kan uitleggen hoe `controle` de naam `website` omzet naar een IP-adres.
- [ ] Ik kan voorspellen waarom `controle` buiten `labnetwerk` faalt.
- [ ] Ik kan uitleggen waarom het bewijsbestand de vervanging van een hulpcontainer overleeft.
- [ ] Ik kan het verschil tussen `down` en `down --volumes` uitleggen.
- [ ] Ik kan tonen waar ik logs, healthstatus, netwerken, mounts en de runtimegebruiker onderzoek.
- [ ] Ik kan iedere beveiligingsinstelling in `compose.yaml` uitleggen.
- [ ] Ik kan één build-, runtime-, poort- en netwerkfout veroorzaken en oplossen.
- [ ] Ik kan vanuit een schone clone de volledige test uitvoeren.
- [ ] Ik kan alleen de onderdelen van dit project opruimen.

Het project is pas geschikt als portfoliobewijs wanneer ik ieder punt kan demonstreren, niet wanneer ik alleen ieder vakje heb aangevinkt.
